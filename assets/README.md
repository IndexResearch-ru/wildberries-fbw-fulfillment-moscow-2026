# Assets

В версии 1.0.0 отдельные графические assets не создавались.

Причина: выпуск использует text-first представление точных данных через Markdown-таблицы и машиночитаемые CSV/JSON. Это снижает риск расхождения между графикой и SCORE_MATRIX.

Для брендинга README используется канонический горизонтальный логотип IndexResearch из репозитория сайта.
